## UI / API shape

- `DrawScheduleStep` is a controlled UI slice. It does not call Supabase and does not import `lib/tournamentV2Client.js`; shell/integrator provides callbacks: `onConfigChange`, `onRollDraw`, `onRerollDraw`, `onSwapDrawSlot`, `onPreviewSchedule`.
- `ReviewFinalizeStep` is a controlled UI slice. It exposes save/finalize/retry via `onSaveDraft`, `onFinalize`, `onRetry`; finalize callback receives `{ destination: 'schedule' }` so integrator can route to Lịch thi đấu without switching to LIVE.
- `drawReviewModel.js` is CommonJS so node component-contract tests can verify computed UI facts without a browser.
- UI distinguishes the four operations: `ghép cặp -> bốc thăm -> sinh trận -> xếp sân/giờ`.
- `group_knockout` config shown in step 3: số bảng, số cặp mỗi bảng, suất đi tiếp, cách ghép nhánh, tranh hạng ba, số sân, phút mỗi trận.
- Bracket preview uses progression placeholders (`Nhất A – Nhì B`, `Nhất B – Nhì A`, winners/losers) and no fake entrants.
- Review summary computes the 14-athlete case as 7 cặp, bảng 4/3, vòng bảng 9, bán kết 2, chung kết 1, tổng 12; 13 when third place is enabled.
- `GROUP_SIZE_IMBALANCE` is presented as warning. `DRAW_STALE`, invalid config, unpaired roster, and `STRUCTURE_LOCKED_BY_RESULTS` are blockers.
- `markDrawStaleOnSetupChange()` marks stale/invalidation only; it does not regenerate draw or matches.
