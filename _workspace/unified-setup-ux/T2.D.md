## Integration notes

- `TournamentWizard.js` now renders `TournamentSetupWorkspace` and T2.B/T2.C steps instead of the old three-step wizard UI.
- Dashboard CTA label for draft tournaments is `Tiếp tục thiết lập`; draft rows route back to `/giai-dau/v2?create=internal&tournamentId=...&divisionId=...`; finalized/non-draft rows still open `/dieu-hanh-giai/:id`.
- `lib/tournamentV2Client.js` exposes aggregate helpers `getDivisionSetup`, `saveDraft`, `previewSchedule`, `finalize` from one client module. `saveDraft` reuses existing `/setup` action path for roster draft persistence and does not introduce a second browser write source.
- Console no longer imports/renders `DivisionSetupPanel`; doubles legacy `TeamsTab` is read-only to avoid two editors writing the same source.
- `TournamentConsoleV2.js` removed `readiness.athletes = true`; athlete readiness is computed from setup aggregate + `setupValidation` domain. Console defaults to operation only when stages contain schedule matches; otherwise it opens the missing setup/draw area and shows a blocking reason.
- Console class prefix changed from `ops-*` to `v2-console-*`; `shell.css` now uses shared light CLB tokens.
