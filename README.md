# 🏓 Hệ Thống Quỹ Pickleball

Ứng dụng Next.js tự động theo dõi quỹ đóng góp của câu lạc bộ Pickleball thông qua tích hợp **SePay Webhook** và **Supabase**.

## ✨ Tính năng

- ✅ Tự động nhận thông báo giao dịch từ SePay (Webhook)
- ✅ Parse nội dung chuyển khoản với cú pháp `PKB [TÊN]`
- ✅ Lưu trữ vào Supabase PostgreSQL
- ✅ Hiển thị bảng xếp hạng "đóng góp" theo tháng
- ✅ Tính tổng quỹ tự động
- ✅ Giao diện đẹp, responsive

## 🚀 Cài đặt Local

### 1. Clone project và cài dependencies

```bash
cd c:\Users\ductu\OneDrive\Apps\Ranking
npm install
```

### 2. Cấu hình Supabase

#### Tạo bảng database

Truy cập [Supabase Dashboard](https://supabase.com/dashboard), tạo project mới, vào **SQL Editor** và chạy:

```sql
-- Tạo bảng lưu lịch sử nộp tiền
create table quy_pickleball (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  nguoi_nop text not null,       -- Tên thành viên (VD: TUAN)
  so_tien numeric not null,      -- Số tiền (VD: 20000)
  noi_dung_goc text,             -- Nội dung gốc từ ngân hàng
  ma_giao_dich text unique       -- Mã tham chiếu (để tránh trùng lặp)
);

-- Tắt RLS (Row Level Security) cho dự án cá nhân
alter table quy_pickleball disable row level security;
```

#### Lấy API credentials

Vào **Project Settings → API**, copy 2 giá trị:
- `Project URL`
- `anon public key`

### 3. Tạo file `.env.local`

Copy file mẫu và điền thông tin:

```bash
cp .env.local.example .env.local
```

Sửa nội dung `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 4. Chạy development server

```bash
npm run dev
```

Mở trình duyệt tại: `http://localhost:3000`

## 🌐 Deploy lên Vercel

### 1. Push code lên GitHub

```bash
git init
git add .
git commit -m "Initial commit: Pickleball fund system"
git remote add origin https://github.com/YOUR_USERNAME/quy-pickleball.git
git push -u origin main
```

### 2. Deploy trên Vercel

1. Truy cập [vercel.com](https://vercel.com)
2. Chọn **Add New Project**
3. Import repository từ GitHub
4. Thêm **Environment Variables**:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. Nhấn **Deploy**

Vercel sẽ cấp domain: `https://your-project.vercel.app`

### 3. Kết nối SePay Webhook

1. Đăng nhập vào [SePay Dashboard](https://my.sepay.vn)
2. Vào **Webhook Settings**
3. Điền URL webhook:
   ```
   https://your-project.vercel.app/api/webhook
   ```
4. Lưu và kích hoạt

## 💰 Cách sử dụng

### Thành viên đóng góp

Chuyển khoản với nội dung:
```
PKB [TÊN] [NỘI DUNG TÙY Ý]
```

**Ví dụ:**
- `PKB TUAN NOP PHAT` → Ghi nhận cho **TUAN**
- `PKB HOANG` → Ghi nhận cho **HOANG**
- `PKB NAM DONG QUY THANG 1` → Ghi nhận cho **NAM**

### Xem bảng xếp hạng

Truy cập website để xem:
- Tổng quỹ hiện tại (theo tháng)
- Bảng xếp hạng người đóng góp
- Lịch sử giao dịch

## 🔍 Chi tiết kỹ thuật

### Regex Pattern

Pattern để extract tên thành viên:
```javascript
/PKB\s+([a-zA-Z0-9_]+)/i
```

- Tìm chữ "PKB" (không phân biệt hoa/thường)
- Lấy từ đầu tiên sau PKB làm tên
- Chuyển thành chữ HOA để thống nhất

### API Webhook Response

```json
{
  "message": "Success",
  "user": "TUAN"
}
```

### Database Schema

| Cột | Kiểu | Mô tả |
|-----|------|-------|
| id | bigint | Primary key (auto) |
| created_at | timestamp | Thời gian ghi nhận |
| nguoi_nop | text | Tên thành viên |
| so_tien | numeric | Số tiền đóng góp |
| noi_dung_goc | text | Nội dung chuyển khoản gốc |
| ma_giao_dich | text | Mã tham chiếu (unique) |
