## Invited-club contract for T2.E/integrator

Draft input:

`invitedClubs: [{ clubId, name, source: "system" | "external", status, externalClubId?, contactName?, contactChannel?, note? }]`

- System invite: `source: "system"`, positive numeric `clubId`.
- External invite: `source: "external"`, provide `name`; `externalClubId` is optional for a previously persisted external club.
- `status` is retained for UI; persisted duplicate records are normalized to `invited` when saved/finalized.
- Save request: `{ action: "replace_invited_clubs", tournamentId, divisionId, invitedClubs, expectedSetupRevision, idempotencyKey }`.
- Resume aggregate: `invitedClubs: [{ tournamentClubId, clubId, externalClubId, name, source, status }]`.
- Finalize continues posting the whole draft; the route consumes `body.draft.invitedClubs`.
