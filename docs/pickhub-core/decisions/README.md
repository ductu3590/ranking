# Architecture Decision Records

ADR ghi lại quyết định làm thay đổi hoặc diễn giải kiến trúc PickHub Core.

## Quy tắc

- Tên file: `ADR-NNN-ten-quyet-dinh.md`.
- Trạng thái: `proposed`, `accepted`, `superseded`, `rejected`.
- Không sửa lịch sử để làm như quyết định cũ chưa từng tồn tại. Quyết định mới supersede ADR cũ.
- ADR accepted phải được link từ tài liệu kiến trúc/phase liên quan.
