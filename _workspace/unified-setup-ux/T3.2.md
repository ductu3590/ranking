## Confirmed blockers

### T3.2-01 - advance lacks frozen error envelope

- Severity: High. Owner: **T1.B** (API/persistence; LEAD if the route ownership remains outside T1.B).
- Reproduction: create a division group stage with at least one unresolved result; `POST /api/tournament-v2/advance` with its `stageId`.
- Expected: HTTP failure using `{ error: { code: 'ADVANCE_RESULTS_INCOMPLETE', message } }`, no transition/temporary semifinal pair.
- Actual: `app/api/tournament-v2/advance/route.js:91` returns only `{ error: 'Stage chưa hoàn tất' }` with 400. The literal `ADVANCE_RESULTS_INCOMPLETE` is absent from the route.
- Impact: UI cannot reliably distinguish incomplete results from a localized message; violates frozen stable error envelope and edge journey requirement. The no-write property remains unproven without live DB.
- Evidence: `evidence/unified-setup-ux/T3.2-edge-results.txt`; failing assertion in `tests/unified-setup-v2/t3.2-edge-journeys.test.js`.

### T3.2-02 - three odd-roster remedies are display-only

- Severity: High. Owner: **T2.B**.
- Reproduction: choose 15 doubles members in setup step 2, then press `add_member`, `reserve_member`, or `switch_format` under the odd-roster notice.
- Expected: each control starts its named, explicit remediation; selection must update pairing/format state without a singleton pair or BYE teammate.
- Actual: `app/giai-dau/v2/setup/pairing/PairingBoard.js:150-152` renders three buttons with `data-choice` but no `onClick`; all are inert. No stable code is emitted because no action is attempted.
- Impact: user cannot resolve `UNPAIRED_MEMBER`, so 15-member doubles cannot reach valid finalize through the promised UI path.
- Evidence: `evidence/unified-setup-ux/T3.2-edge-results.txt`; failing assertion in `tests/unified-setup-v2/t3.2-edge-journeys.test.js`.
